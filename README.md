# Вариант 02. Параллельный анализатор файлов

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Файлы, async I/O, Parallel.ForEachAsync, Channel, Stopwatch, IDisposable

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Найти текстовые файлы в каталоге.
2. Последовательно подсчитать строки, слова и символы.
3. Реализовать параллельный анализ файлов.
4. Ограничить число одновременно обрабатываемых файлов.
5. Сравнить последовательный и параллельный режимы с Stopwatch.
6. Обрабатывать ошибки отдельных файлов, не прекращая весь отчёт.
7. Сохранять итоговый отчёт через корректно закрываемый поток.

## Дополнительные задания
8. Построить pipeline через bounded Channel и фиксированных worker-ов.
9. Добавить JSON-отчёт.
10. Сохранять параметры анализа в HKCU.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
